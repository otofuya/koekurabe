# レビュー比較サイト スターターキット

前身プロジェクト（UMAP 商品地図 → レビュー分析への転換）で得た知見・実測値・
動作するコード・実データを、新規プロジェクト用にまとめたもの。

**このフォルダごと新しい作業ディレクトリに移して、`00_最初の指示文.md` の内容を
Claude Code に貼れば始められます。**

## 中身

| パス | 内容 |
|---|---|
| `00_最初の指示文.md` | **ここから読む。** Claude Code に貼る文と、進め方 |

## 移動したあとにやること

```bash
# 1. 新しい作業ディレクトリに置く
mv _new-project-starter ~/my-review-site && cd ~/my-review-site

# 2. Claude Code を起動して 00_最初の指示文.md の内容を貼る
```

`.claude/skills/` はそのまま置いておけば自動で読み込まれます。
`CLAUDE.md` もプロジェクト直下にあれば自動で読まれます。

## このキットが省いてくれること

以下はすべて実際に試して分かったことで、知らずに始めると再発見に丸一日かかります。

- Amazon のレビュー本文が取れない**理由**（規約ではなく実測した挙動）
- 楽天レビューのURL構造とページ送りの形式
- カバレッジが27%で頭打ちになる理由と、上げるために必要なもの
- Gemini のモデル選択（間違えると1/5で枠切れになり、静かに空になる）
- **言及が最も多い観点が、最も軸に向かないこと**
- 収縮を入れないと図が逆さになること
- 引用の12%が偽物であること（別レビューの断片を繋いだ文）
- 色違いの統合が未解決であることと、試して失敗した3つの方法

## 前提

- Node.js 22 以上
- `GEMINI_API_KEY`（観点抽出に必要。無料枠 Flash Lite で1日500件）
- 楽天・Amazon の資格情報は無くても画面は作れます（データが同梱されているため）
