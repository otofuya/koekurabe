# ポートフォリオ前の認識合わせ（30問）

作成日：2026-09-25。前提資料：[05_現状の確認.md](05_現状の確認.md)

BakenLog・OnomaUI と同じ順で進めます。

1. **この質問に回答**（今ここ）
2. **UIポートフォリオ**を作る。BakenLog・OnomaUI と同じ型のキャンバス：説明のボード、案の比較、実寸の画面（スマホ・PC）、触れる試作
3. 承認または直しを受けてから、実装する

## 回答のしかた

- 「回答：」に書き込むか、チャットで番号を付けて答えてください（例：`Q01 A、Q02 D、Q12 ①②③`）
- 選択肢はヒントです。複数選択・組み合わせ・自由記述・「お任せ」「不要」も有効です
- **空欄の質問は「推奨」で進めます。** 全部を埋める必要はありません。特に大事なのは ★ の付いた9問です
- 見た目の好みは言葉だけでは決めにくいので、ポートフォリオで3案を並べて選んでもらいます

## ポートフォリオの作り方（答えなくてよい。違えば教えてください）

以下は OnomaUI の回答を引き継いで進めます。

- **量と形：** OnomaUI と同じくらい。キャンバス1つに、ページ「ポートフォリオ」（決めたこと・現状・コンセプト・体験・デザイン言語・名前・部品・各画面・信頼・収益・画面一覧・要件の対応表）、「案の比較」、「画面（実寸）」、「触れる試作」
- **画面の大きさ：** スマホ 390、PC 1440
- **中身：** 実際の商品名と件数（`data/` の値）で描く。商品画像はキャンバスに載せず、図形で代わりにする（楽天の画像を別の場所へ持ち出さないため）
- **元のファイル：** `design/portfolio/src/`（OnomaUI と同じく、生成したものはリポジトリに入れない）
- **実装の技術：** 承認後に改めて提案する（今の素の TypeScript＋Vite を活かすか、OnomaUI と同じ React に寄せるか）
