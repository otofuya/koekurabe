## 2. 設定（チャットに貼らない）

プロジェクトの直下に2つのファイルを作る。どちらも git に入らない（`.gitignore` 済み）。

**`.dev.vars`**（データを作るときの鍵）
```
GEMINI_API_KEY=...
RAKUTEN_APPLICATION_ID=...
RAKUTEN_ACCESS_KEY=...
```

**`.env.local`**（サイトを作るときの設定）
```
VITE_RAKUTEN_AFFILIATE_ID=...
VITE_SITE_URL=https://koekurabe.pages.dev
# 公開の許可が出るまで入れない
# VITE_SITE_PUBLIC=1
```

## 3. データを作る

```bash
# イヤホン：読み直して（約30分・楽天のページが1枚10秒ほどかかる）、抽出し直す（約51回）
node --experimental-strip-types scripts/fetch-reviews.mjs earbuds
node --experimental-strip-types scripts/extract-aspects.mjs earbuds

# 新しいカテゴリ：一覧 → 読む → 抽出（各約60回）
node --experimental-strip-types scripts/fetch-item-list.mjs lotion --dry-run   # まず見るだけ
node --experimental-strip-types scripts/fetch-item-list.mjs lotion
node --experimental-strip-types scripts/fetch-reviews.mjs lotion
node --experimental-strip-types scripts/extract-aspects.mjs lotion

npm run validate:data && npm test
```

- Gemini は Flash-Lite に固定（無料枠 1日500回）。3つのカテゴリで約170回
- `fetch-shop-reviews.mjs` はイヤホンでは回さない（前回、足せたのは3件だけだった）
- 2026-09-26 の読み直しで、Liberty 4 など6商品が0件になった（docs/02 第13節）。抽出は、読み直せなかった・前より少なかった商品の前の結果を残す（`--replace-all` で捨てる）
- 403 が返ったら止まる。回避しない

## 4. サイトを作って公開する

```bash
npm run build      # 検査 → vite build → 101ページの書き出し・サイトマップ・シェア画像
npx wrangler pages dev dist --port 8788   # 置き場と同じ動きを手元で確かめる
```

公開（**オーナーの許可のあと**）：
1. Cloudflare のアカウントを作る（無料）
2. この PC で `npx wrangler login`（ブラウザでログイン）
3. `npx wrangler pages deploy dist --project-name koekurabe`
4. 検索に出すときは `.env.local` に `VITE_SITE_PUBLIC=1` を入れて、もう一度 build と deploy
5. Google Search Console にサイトマップ（/sitemap.xml）を登録する

Cloudflare Pages の無料枠：転送量の上限なし・商用利用可・ビルドはこの PC でするので枠を使わない。
