## コンセプト（案）

**買った人の声で描いた、商品の地図。** 順位ではなく位置で見せる。

1. 似ている・違うが見える — 近さ＝買った人の声（観点ごとの満足・不満の出方）の似かた。好きな商品を真ん中に置くと、違いが方角で分かる
2. 不満が先に見える — 商品の丸の周りの「声のリング」は、不満（オレンジ）から描く
3. 数字はごまかさない — 件数は必ず「読んだ数」と一緒。AI 分類を明示。引用は原文と照合
